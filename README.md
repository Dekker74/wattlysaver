# WattlySaver

App mobile-first per il monitoraggio intelligente dell'energia: consumi in tempo reale, budget mensile, programmi ECO e piano di abbonamento. Design conciso in tonalità viola, ispirato al concept Framer di riferimento.

> I dati mostrati sono illustrativi e non reali.

## Funzionalità

- **Home** — saluto, budget del mese, potenza/energia istantanea, settimana e suggerimento ECO.
- **Consumi** — grafico delle 24 ore, storico settimanale e dispositivi attivi.
- **Budget** — limite mensile regolabile, ripartizione delle spese e andamento semestrale.
- **Esplora** — attivazione/disattivazione dei programmi ECO con risparmio stimato.
- **Piano** — scelta tra fatturazione mensile e annuale.

## Stack

Next.js (App Router), React, TypeScript, CSS con design token dedicati. Nessuna dipendenza UI esterna.

## Sviluppo

```bash
npm install
npm run dev
```

Apri [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # build di produzione
npm run typecheck
```
